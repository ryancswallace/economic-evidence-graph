# Economic Evidence Graph

A versioned, auditable evidence layer for economic research and policy synthesis

The local platform implements canonical identity and lineage, governed
real-source acquisition, immutable normalized evidence, explainable hybrid
retrieval with strict historical cutoffs, collaborative reviewed projects,
R/Python clients, and eight bounded agent tools. AWS deployment and institutional
production acceptance remain deferred.
